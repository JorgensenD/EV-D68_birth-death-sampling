Code and data for the submitted manuscript "Reconstructing enterovirus D68 clade-specific transmission dynamics using phylodynamics and association with acute flaccid myelitis."

## Downloading the required sequence data
The included data and code allow a user to recreate the analyses performed in the manuscript. The sequence data are not included here but are publicly available on genbank with the accession numbers provided in the [metadata](./data/metafile.csv). Code to perform a genbank download in R and prepare a metadata file is provided in the [code](./code/1_genbank_pull.R) folder.

## Subsampling the data
In this analysis we perform multiple samples of the data under different schemes to test the sensitivity of the model to the included sequences and the sampling scheme used. The code used to generate these samples is provided in [2_subsampling_removeambig.R](./code/2_subsampling_removeambig.R) and code to plot histograms of the samples is provided in [3_plot_samples.R](./code/3_plot_samples.R).

## Analyses with BEAST2
Samples generated were used to run a phylodynamic model with [BDMM-Prime](https://github.com/tgvaughan/BDMM-Prime) in BEAST2. The BEAST code required for these analyses is provided in [BEAST_scripts](./code/BEAST_scripts). These files use the [feast](https://github.com/tgvaughan/feast) package to load sequence data and parse dates, allowing them to be run on any of the pairs of alignments generated. Feast needs to be installed via the beauti package manager or command line to run the scripts. The xml files can be added to any of the sample folders generated in the previous section, a change will need to be made to the file path for the sequence data to match the path on your system. The included scripts log the population trajectory every 250000 iterations. This can be commented out to generate only the Rt trajectories which is faster and less memory intensive to run. Ambiguous sequence dates need to be injected into the XML template provided using the R script [4_XML_tags_tipdating.R](./code/4_XML_tags_tipdating.R).

To test sensitivity to infectious period we ran the model three times on the same sample, changing only the time to recovery. The scripts for this sensitivity analysis can be found in [sensitivity_infectious_period](./code/BEAST_scripts/sensitivity_infectious_period). Considering the B clade independently from the C clade and incorporating an international background population, the other sensitivity analyses with the BDMM-prime model, also required custom XML files. These are included in the [BEAST scripts](./code/BEAST_scripts/) folder.
The MASCOT-skyline analysis was constructed in BEAUti following the [GitHub tutorial](https://github.com/nicfel/MascotSkyline-Tutorial).

## Generating plots
The main results presented in the manuscript can be generated with the code in [5_main_results.R](./code/5_main_results.R). These plots also require the metadata file for the full dataset and the reported AFM cases which can be found in [data](./data/).

## System requirements
The code has been tested on R version 4.4.1 and BEAST versions 2.7.4 and 2.7.7. Package dependencies for R are included in the respective code files. The BEAST analysis depends on the BDMM-Prime package (v > 2.2.2) and feast package (v > 10.3) which are installed via the BEAST package manager. The code is independent of operating system but is tested primarily on MAC OS 15. The Included scripts and datasets can be used to recreate the figures and analyses presented in the main text of the paper. This is possible by cloning this repository locally or by manually downloading the relevant files. Plotting from these data should be almost instantaneuos on a standard desktop computer. To run the full analysis takes around 20 days from start to finish, with each iteration of the BEAST analysis (48 used in total here) split across multiple CPU cores. Here this was carried out on a high performance computing cluster, although each iteration can be run locally with more restricted computational resources. The R analyses can be carried out on a standard desktop or laptop computer within a few hours.
